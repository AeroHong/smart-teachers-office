# 스마트 교무실

> 교무 업무 통합 관리 시스템 — 출결 · 보강 · 연수 · 평가 · 세특 점검 · 검인정도서 · 업무 메신저

- 교무 포털: **https://seonyoo-system.web.app**
- 업무 메신저(웹): **https://smart-school-dashboard.web.app** — Windows/macOS 데스크톱 앱으로도 제공

---

## 소개

선유고등학교 교사들의 반복적인 교무 업무를 디지털화하려고 시작한 웹 기반 통합 관리 시스템입니다.
종이 대장·전화 연락으로 하던 보강 신청과 호명 출석을 **실시간 웹 플랫폼**과 **QR·버튼 출석**으로 바꾸는 데서 출발해,
지금은 평가 계획 제출, 세특 점검, 검·인정도서 선정 같은 학기 단위 업무와 **쿨메신저를 대신하는 업무 메신저**까지 다룹니다.

모든 데이터는 `/schools/{schoolId}` 아래에 학교별로 분리되는 **멀티테넌트 구조**라, 다른 학교도 같은 시스템에서 독립적으로 쓸 수 있습니다.
학교 Google Workspace 계정으로 로그인하고, 학교 관리자가 가입을 승인하면 역할에 따라 권한이 나뉩니다.

## 앱 구성

| 앱 | 설명 |
|----|------|
| **교무 포털** (`apps/portal`) | 아래 업무 모듈과 학교 관리자·시스템 관리자 화면 |
| **업무 메신저** (`apps/dashboard`) | 채널 · 캔버스(업무 글) · DM · 알림 · 학사일정 · 구성원 · 보강 |
| **데스크톱 앱** (`apps/desktop`) | 업무 메신저를 감싼 Electron 앱 — 트레이 상주, OS 알림, 재실 자동 감지, 자동 업데이트 |
| **호출 키오스크** (`apps/kiosk`) | 교무실 앞에서 학생·방문자가 선생님을 호출하는 화면 |

StudentHub(학적·고사 관리)와 ExamCore(고사 업무)는 별도 앱이며 로그인과 학교 데이터를 함께 씁니다.

## 주요 기능

### 1. 스마트 출결 — 자세히: [ATTENDANCE.md](./ATTENDANCE.md)

| 기능 | 설명 |
|------|------|
| 이벤트 생성 | 조회·수업·방과후·행사·기타, 단일/반복(요일별 조회~종례) 스케줄, 공동 담당교사 |
| QR 체크인 | 학생이 QR 스캔으로 즉시 출석 (별도 앱 불필요) |
| 교시별 버튼 출석 | 학생이 자기 이름 버튼을 눌러 출석, 지각·조퇴·종일 결석 사유 이월, 전체화면(키오스크) 보기 |
| 라이브 세션 | 출석 시작 → 마감, 미출석 자동 처리 (Cloud Functions) |
| 외출 관리 | 외출·복귀 기록, 수업 시간 1/3 초과 경고 |
| 실시간 현황 | QR·출석·미출석 3분할, 등수·메달, 전원 출석 축하, 오늘의 행운번호 |
| 학생 그룹 | CSV/엑셀 업로드, 그룹 공유 |
| 통계·기록 | 이벤트별·학생별 통계, 날짜별 시트로 엑셀 내보내기 |
| 학생 공지·포털 | 이벤트별 공지와 확인 현황, 학생 전용 화면(`/student`) |

### 2. 보강 신청 — 자세히: [SUBSTITUTE.md](./SUBSTITUTE.md)

| 기능 | 설명 |
|------|------|
| 보강 일괄 등록 | 스프레드시트 형식으로 여러 건 동시 입력, 엑셀 붙여넣기 지원 |
| 오픈 예약 | 특정 시각 이후에만 신청 가능하도록 공개 시간 예약, 초 단위 카운트다운 |
| 실시간 카드 목록 | 신청 가능·예정·마감 상태를 색상으로 구분 (4주 범위) |
| 신청 / 취소 | 원클릭 신청, 취소하면 즉시 다른 교사에게 다시 노출 |
| 관리자 지정·수정 | 관리자가 보강 교사를 직접 지정하거나 카드를 수정·삭제 |
| 내 신청 내역 · 현황판 · 명예의 전당 | 이력 조회, 월별 필터, 월별·전체 랭킹 |
| Excel 내보내기 | 관리자 전용, 구간 선택 다운로드 |

업무 메신저에도 같은 데이터를 쓰는 보강 화면(목록·내 현황·현황판)이 있습니다.

### 3. 연수 서명부 — 자세히: [TRAINING.md](./TRAINING.md)

연수·회의 참석 명단을 만들고 교사가 직접 서명, 서명 현황·PDF·Excel 출력, 관리자용 명단 프리셋.

### 6. 관리자

- **학교 관리자** (`/admin`) — 계정 승인·사전 등록, 교직원 기본 배정·과목 배정, 학생 명단(Workspace 동기화), 과목(교육청 배당표 업로드), 사무실 자리 배치, 학사일정, 대시보드 모듈 노출, 검인정 설정, 데스크톱 설치 현황 — [ADMIN_STRUCTURE.md](./ADMIN_STRUCTURE.md)
- **시스템 관리자** (`/super-admin`) — 학교·도메인 등록, 게스트 학교 관리

## 권한 체계

| 역할 | 내용 |
|------|------|
| 시스템 관리자 (`super_admin`) | 전체 학교·도메인 등록·관리 |
| `school_admin` / `admin` | 학교 관리자 — 가입 승인·역할 변경, 사전 등록, 학교 설정 |
| `headmaster` / `principal` | 교장 / 교감 — 결재·확인 화면, 일부 관리 권한 |
| `teacher` | 교사 (강사는 staffType으로 구분) |
| `student` | 학생 — 출석 체크인과 학생 포털만 |
| `pending` / `rejected` | 승인 대기 / 거절 |

**가입 흐름**: 이메일 도메인은 학교를 *추천*할 뿐이고, 실제 진입은 **학교 관리자 승인**이 결정합니다.
관리자가 미리 등록해 둔 교직원(`preApproved`)은 첫 로그인 때 승인 없이 바로 활성화되고, 학생은 `studentRegistrations`로 자동 등록됩니다.
자세한 설계는 [SECURITY.md](./SECURITY.md).

## 기술 스택

| 영역 | 기술 |
|------|------|
| Frontend | React 18 + Vite, react-router-dom v6, MUI |
| 데이터베이스 | Firebase Firestore (실시간 구독, 보안 규칙 기반 직접 접근) |
| 인증 | Firebase Authentication (Google) |
| 서버리스 | Firebase Cloud Functions (Node · Python) — Workspace·캘린더 동기화, 링크 미리보기, 메일 발송, 호출, 세션 자동 관리 등 |

| 데스크톱 | Electron + electron-updater |
| 기타 | qrcode.react, react-signature-canvas, ExcelJS(동적 로드), DOMPurify |

Firestore 컬렉션 구조는 [DB_STRUCTURE.md](./DB_STRUCTURE.md)에 정리돼 있습니다.

## 로컬 개발

```bash
npm install
npm run dev              # 교무 포털
npm run dev:dashboard    # 업무 메신저
npm test                 # 순수 로직 테스트
npm run test:rules       # 보안 규칙 테스트 (Firestore 에뮬레이터)
npm run deploy           # 포털 빌드 + 배포
npm run deploy:dashboard # 메신저 빌드 + 배포
```

`.env`에 `VITE_FIREBASE_*` 값이 필요합니다. 전체 명령은 [CLAUDE.md](./CLAUDE.md)의 "개발 워크플로우" 참고.
