# 분반 배정(smart-class-flow) 4단계 — StudentHub 연동·나이스 업로드

> 상태: **구현(2026-11-04)**. 처음 계획(2026-11-03)은 ClassFlow가 학생 문서에 직접 쓰는 안이었지만,
> 학적·선택과목 등록은 StudentHub에서 하는 일이라(2월 신학년 준비: 진급 → 반편성 → 선택과목 나이스 편성) **StudentHub 선택과목 화면이 가져와서 저장**하는 방식으로 바꿨다.

## 흐름

```
[11월] 수강신청(교육부 프로그램) → ClassFlow 새 작업(원본 엑셀 그대로) → 배정 → 저장
[2월]  StudentHub 반편성 등록(nextPlacement) 또는 학년도 전환(진급)
       StudentHub 선택과목 → 학년도·학년 → 「분반 배정에서 가져오기」 → 초안 확인 → 저장(electiveSubjects)
       같은 화면 「나이스 업로드 파일」 → 과목·분반별 엑셀 zip → 나이스 업로드
```

## 학생 연결

- ClassFlow 작업의 학번은 **수강신청 당시 학번**이다. 학번 첫 자리(학년)로 그 학번의 학년도를 계산한다:
  `학번 학년도 = 작업 학년도 − (작업 학년 − 학번 학년)` (예: 2027학년도 2학년 작업, 학번 10101 → 2026학년도 학번)
- 그 학년도 학번으로 재적 학생을 찾고(`findStudentIn` — 진급 뒤면 `placements` 이력), 대상 학년도 자리(`placementIn` — 진급 뒤 학적 또는 반편성)로 옮긴다.
- 작업에 이름이 있으면 학생 이름과 맞춰 본다(다르면 넣지 않음). 못 찾은 학생·반편성 없는 학생·미배정 과목은 확인 목록에 남긴다.
- 그다음은 엑셀 올리기와 같은 `planXlsxDraft` — 과목명을 교육과정 이름으로 맞추고, 그 학기 전체를 바꾼다(작업에 없는 저장 과목은 비움).

코드: StudentHub `src/lib/classflowImport.js`, `src/pages/electives/ClassflowImportDialog.jsx`

## 반영 형식 — `students.electiveSubjects`

| 필드 | 값 |
|---|---|
| `subjectName`·`subjectId` | 교육과정 과목명(입학년도 범위)과 ID, 못 찾으면 이름만 |
| `classNo` | 분반 기호 = 그룹 글자(`A`~`E`), 같은 그룹 2분반이면 `A1`·`A2` (StudentHub `validSection`이 허용) |
| `semester` | 작업의 학기(1·2학기 같음 학년이면 두 학기) |
| `year`·`grade` | 작업의 학년도·학년 |

저장·로그·업로드 기록(`electiveImports`, 파일 이름 `분반 배정(ClassFlow) {작업명}`)은 엑셀 올리기와 같다.

## 나이스 업로드 파일

받은 양식(`[나이스업로드] 지구시스템과학_C_2학년 2학기 선택과목.xlsx`)과 같게 과목·분반마다 파일 1개:

- 파일명 `[나이스업로드] {과목}_{분반}_{학년}학년 {학기}학기 선택과목.xlsx`, 시트명 `{과목}_{분반}`(31자)
- 열 `학년도 · 과정 · 계열 · 학년 · 학과 · 반 · 번호 · 성명`, 반·번호는 텍스트 서식(@), 반·번호 순
- 과정·계열·학과 기본 `주간 · 일반계 · 일반학과`(창에서 고치면 학교별로 기억)
- 저장된 값만 쓴다(표에 저장 안 한 칸이 있으면 경고). 분반 없이 과목만 저장된 학생은 빼고 알린다
- zip 하나로 내려받기(JSZip)

코드: StudentHub `src/lib/neisElectiveExport.js`, `src/pages/electives/NeisExportDialog.jsx`

## 남은 것

- 나이스에 실제로 올려 보고 양식 차이(헤더 서식·학과명 등) 확인
- 반영 되돌리기는 따로 두지 않는다 — 선택과목 표의 되돌리기·다시 가져오기로 충분한지 써 보고 판단
